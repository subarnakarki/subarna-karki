# Subarna Karki — Portfolio

A single-file, animated portfolio/resume site for **Subarna Karki**, Senior / Staff Quality Engineer.

Built with HTML5, Tailwind CSS (CDN), custom CSS animations, and vanilla JavaScript — no build step.

## Run locally
Open `index.html` in any modern browser, or serve the folder:
```
python3 -m http.server 8000
```
then visit http://localhost:8000

## Deploy on GitHub Pages
1. Push to GitHub (this repo).
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
3. Select branch `claude/portfolio-website-github-pages-84jv1t` (or `main` after merge) and folder `/ (root)`.
4. Save. The site publishes at your GitHub Pages URL within a minute.

`.nojekyll` is included so the static HTML is served as-is.
